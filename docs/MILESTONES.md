# Milestones

- **M0 — Foundation:** scope, CI, publishing contract, syllabus and POSIX baseline.
- **M1 — Unix I/O:** descriptors, files and directories.
- **M2 — Processes:** process model, fork/exec/wait, environment.
- **M3 — Signals and IPC:** signals, pipes and IPC.
- **M4 — Terminals:** TTY/PTY programming and interactive tools.
- **M5 — Networking:** sockets, resolution and robust protocol I/O.
- **M6 — Concurrency:** pthreads and synchronization.
- **M7 — Production systems code:** services, security, tracing and portability.
- **M8 — Complete course:** capstone, review and publishing qualification.

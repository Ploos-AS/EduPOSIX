# Contributing

This project is educational material. Keep examples small, readable and reproducible.

## Rules

- Explain concepts before relying on them.
- Compile examples with strict warnings.
- Keep platform-specific code clearly identified.
- Never commit proprietary ROMs, operating-system files, SDK material, malware, credentials or generated build products.
- Documentation/course material is CC BY-SA 4.0 unless stated otherwise; original example code is MIT.
- English is the canonical source during early development; Norwegian translations should preserve code and technical meaning.

## Quality gate

A milestone is not complete merely because prose exists. Examples must build in the supported environment and automated checks must pass where practical.

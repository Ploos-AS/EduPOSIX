# EduPOSIX course source

EduPOSIX assumes the core C knowledge taught by EduC.

Every API introduced in this course should be labelled as one of:

- **ISO C**
- **POSIX**
- **Linux-specific extension**

The distinction is part of the curriculum, not merely a portability note.

Major labs progress from file descriptors and processes through IPC, terminals, sockets, threads and a final systems-programming project.

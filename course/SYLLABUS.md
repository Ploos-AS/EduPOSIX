# EduPOSIX syllabus

1. From C to POSIX
2. File descriptors and low-level I/O
3. Files, directories and metadata
4. Processes and process identity
5. `fork`, `exec` and waiting
6. Environment and process state
7. Signals
8. Pipes and redirection
9. IPC
10. Terminal programming and PTYs
11. Time and clocks
12. Users, groups and permissions
13. Sockets and networking
14. Name resolution
15. Threads and synchronization
16. Daemons and services
17. Robust parsing and secure systems code
18. Debugging, tracing and profiling
19. Portability across POSIX systems
20. Capstone: build a small Unix system program

Linux extensions may be taught in clearly marked sidebars/labs, never silently presented as POSIX.
